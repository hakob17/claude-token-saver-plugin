# Resume

1. Treat the pasted handoff note as the complete context of the earlier conversation. Don't redo research, re-read files or re-ask questions it already settles.
2. Reply in at most 3 lines: the goal, and the next step about to be taken.
3. Start on the first item under **Next steps** (or on any instruction the user gave with the command) in the same reply.
4. If the note is missing something essential for the next step, ask one specific question instead of guessing.
5. Keep the economical style: brief answers, no recaps.
