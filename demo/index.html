Routing proxy for Claude Code experimental

Claude Code talks to a local proxy via ANTHROPIC_BASE_URL. The proxy picks the model for each request before anything is generated. Try the scenarios below.

    Rules

    • Budget failover: at 100% of the monthly budget, requests for Opus are rewritten to Sonnet.
    • Subagents (optional): requests without the Agent tool are subagents and can go to Haiku or Sonnet.
    • Switch only at boundaries: a new conversation, or a new user turn while the context is ≤ 40k tokens. Never in the middle of a tool loop, so the prompt cache and the thinking chain stay valid. Past 110% the switch happens at the next turn regardless of context size.
    • Thinking blocks signed by the old model are dropped from turns before the switch point.
    • Fail open: if the cheaper model rejects a rewritten request, the original is resent. That combination is then skipped for later conversations.
