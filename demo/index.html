Type a request or pick one. The classifier reads only your words (no tool output, no injected reminders), scores them, and sends the turn to the tier it needs. The model then stays pinned for the whole turn, so the prompt cache and thinking chain stay valid.

    3. Team gateway: limits that act on the next request

    One shared proxy for the team. Every engineer has a key, a monthly limit and a rule for what happens at the limit. Send a request for each engineer, then act as their manager.

    Managers see all of this, plus spend by model, savings from routing, router decisions and an audit trail, in a dashboard at /admin. Keys are stored as hashes. Blocked requests never reach the API.

    4. Prompt hints: private, after costly turns

    The gateway records each prompt's shape, never its text: whether it names files, says how to check the result, or asks for something huge in one line. After a costly turn that missed a pattern, a Stop hook shows a hint under the reply. It's shown to the engineer only; the model never sees it.

    How it stays safe

    • Decides before generation. Hooks can only block Opus after it has written the code; the proxy picks the model first. That's the difference between +46% and −52%.
    • Switches only at turn boundaries. Never in the middle of a tool loop. Moving down a tier only when re-caching is cheap (new conversation, context ≤ 40k, or down to Haiku).
    • Over budget, moves down. Once the budget is spent, the next turn leaves Opus whatever the context size; never in the middle of a turn.
    • Moves up after trouble. 3+ failing commands in a turn escalate the next one, unless it's a plain question. Negations ("don't change anything") don't count as edits.
    • Fails open. If the API rejects a rewritten request, the original is sent once and that combination is skipped later.
    • Works with subscriptions. Your own login passes through; the gateway key travels in a header.
    • Private by design. Prompt text is never stored. Hints go only to the engineer; managers see team totals.
